Class QueryParams

Builder for JSON:API query parameters.

Standard JSON:API members (include, fields[type], sort, filter[...], page[...]) are first-class, other parameters can be added with custom. The builder methods change this instance and return it for chaining, merge and copy return a new instance.

Query parameters

Further query parameters such as sorting, filtering or paging can be passed to Document.fromURL with the QueryParams builder:

const params = new JsonApi.QueryParams()
  .sort(['-created', 'title'])
  .filter('author', '5')
  .page('size', 50)
  .include(['author']);
const articles = await JsonApi.Document.fromURL(new URL('http://example.com/articles'), context, undefined, params);

This requests http://example.com/articles?sort=-created,title&filter[author]=5&page[size]=50&include=author (URL-encoded). The given URL is not changed. Unlike sparse fields, the parameters only apply to this request and not to related documents. The filter syntax as well as the supported sort fields and page members depend on the server.

For a nested filter, pass the key as a path of segments instead of writing the inner brackets:

const params = new JsonApi.QueryParams().filter(['simple', 'primary', 'id__in'], '1,2');

This adds filter[simple][primary][id__in]=1,2, like filter('simple][primary][id__in', '1,2'). Path segments must be non-empty strings without brackets.
